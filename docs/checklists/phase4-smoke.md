# Phase 4 스모크 체크리스트 (녹음 중 시스템 동작 + 사운드 + 붙여넣기)

사전: `./scripts/make-app.sh --install && open -a Wisp`
재설치 후 **손쉬운 사용 권한**을 시스템 설정에서 한 번 껐다 켜야 단축키가 동작한다(ad-hoc 서명).

## 미디어 일시정지 (기본 모드 = 일시정지)
- [ ] 음악(Music/Spotify) 또는 영상(YouTube 등) 재생 중 ⌃ 녹음 시작 → 재생이 멈춘다
- [ ] 말하고 단축키를 떼면 → 재생이 재개된다
- [ ] 아무것도 재생 중이 아닐 때 녹음해도 → 재생이 잘못 시작되지 않는다(안전 강등)

## 모드별 오디오 동작
- [ ] 모드 패널 → "녹음 중 오디오"를 음소거로 변경·저장 → 녹음 중 시스템 출력 0, 종료 시 원복
- [ ] 볼륨 낮춤으로 변경 → 녹음 중 출력 15%, 종료 시 원복
- [ ] 유지로 변경 → 녹음해도 미디어/볼륨 그대로

## 사운드 피드백
- [ ] 녹음 시작 시 시작음(Tink), 결과 처리 완료 후 완료음(Glass)
- [ ] 일반 패널에서 "사운드 피드백" 끄면 → 무음

## 붙여넣기
- [ ] 자동 붙여넣기 켜짐(기본) → 결과가 활성 앱에 바로 입력됨
- [ ] 자동 붙여넣기 끄기 → ⌘V 미주입, 클립보드에만 남고 HUD "⌘V로 붙여넣기" 표시
- [ ] 클립보드 복원 켜기 → 붙여넣은 뒤 직전 클립보드 내용이 복귀(붙여넣은 텍스트는 앱에 들어감)

## 하위호환 (회귀)
- [ ] 기존 config.json·modes/*.json 그대로 두고 실행 → 핫키·codex 경로 등 기존 설정 유지(리셋 안 됨)
      (자동 테스트로도 커버: ConfigStore/ModeStore 구버전 디코딩 테스트)
